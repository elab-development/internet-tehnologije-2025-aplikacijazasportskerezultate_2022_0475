# APLIKACIJA ZA PRAĆENJE SPORTSKIH REZULTATA I STATISTIKA

Web aplikacija za prikaz sportskih događaja, rezultata i statistike.

Projekat je razvijen u okviru kursa **Internet tehnologije** na Fakultetu organizacionih nauka.

Aplikacija omogućava pregled sportskih događaja, rezultata utakmica i statistike timova kroz modernu web aplikaciju razvijenu korišćenjem **Next.js** framework-a.

---

# Tehnologije

U projektu su korišćene sledeće tehnologije:

- Next.js
- React
- Node.js
- Prisma ORM
- REST API
- Swagger UI
- Docker
- Docker Compose

---

# Funkcionalnosti

Aplikacija omogućava:

- pregled sportskih događaja
- prikaz rezultata utakmica
- prikaz statistike događaja
- rad sa REST API servisima
- pregled API dokumentacije kroz Swagger
